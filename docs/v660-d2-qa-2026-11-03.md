## 3. DETALJERTE FUNN

### F1 — Posisjonsfilter dreper alle kandidater (P0, blokker)
`src/fitment-v1/catalogue-candidates.ts:143-155` filtrerer på tekst i `varenavn`:

```ts
if (glassKlasse === 'frontrute') return /FRONT|FRONTR|WINDSHIELD|VINDUS/.test(n);
if (glassKlasse === 'bakrute')  return /BAK/.test(n);
if (glassKlasse === 'dor')      return /DØRRUTE|DORRUTE|DØR|DOOR/.test(n);
...
```
Katalognavnene inneholder sjelden disse ordene. `MERCEDES CLA-CLASSE 4D COUPE 13-` er en frontrute
(eurokode `5524AGACMUVZ`), men matcher ingen av nøkkelordene.

**Målt effekt:** nøyaktig samme kall uten `glassklasse` gir kandidater; med `glassklasse` gir det 0.

**Autoritativ klassifisering finnes allerede** — `klassifiserGlass()` i `src/glass-posisjon.ts:329`
(navn + eurokode + typekode, med konfliktdeteksjon). Den gir for de 54 `MERCEDES CLA`-radene:
`sidefamilie: 43 · bakrute: 10 · frontrute: 1`. Det naive filteret gir 0 for alle.

### F2 — Familie-regex matcher «CLASS» (P0, blokker)
`src/fitment-v1/catalogue-candidates.ts:52`:
```ts
{ merke: 'MERCEDES', re: /CLA/, familie: 'CLA' },
```
`/CLA/` matcher `E-CLASS`, `C-CLASSE`, `S-CLASSE`, `A-CLASS`, `M-CLASSE`. Resultat for
`AJ95429` (CLA 200 D 4MATIC 2016), uten klassefilter:

```
25 kandidater · posisjonstyper: { bakrute: 6, sidefamilie: 11, frontrute: 7, ukjent: 1 }
modeller: MERCEDES W210 E-CLASS, MERCEDES M-CLASSE W163, MERCEDES W163 M-CLASS,
          MERCEDES S-CLASSE W220, MERCEDES C-CLASSE W203, MERCEDES A+B CLASSE,
          MERCEDES A+B-CLASS 5D, MERCEDES A-CLASS 5D, MERCEDES W169 A-CLASS
inneholder ekte CLA-frontrute 5524AGAC? false
```

**Konsekvens:** fikses F1 alene, slipper dette gjennom som «frontrute til din CLA» — 7 frontruter
for E-CLASS/M-CLASS/C-CLASS/A-CLASS. Det er nøyaktig den feilen `MANUAL_REVIEW`-sperren skal hindre.
**F1 og F2 må rettes i samme endring.**

### F3 — Åpne intervaller + ingen generasjonssjekk (P0, blokker)
`aarIntervall()` gir `til = null` for «91-», «03-», «13-»; `matchClassDCandidates` tolker `null` som
`Infinity` (`catalogue-candidates.ts:157-168`). Dermed matcher 1991- og 1980-rader en 2005-bil:
```
SU18018 (VW Transporter 2005), uten klassefilter:
  21416YP  VW TRANSPORTER  91-
  7901CL   VW TRANSPORTER,80-
  26501GN  VW TRANSPORTER  DOUBLE CAB  03-     ← riktig generasjon
```
Det finnes generasjonshint i katalogen (`T4`, `T5`, `E36`, `W163`) og i `ParsedRow.generasjon`,
men de brukes aldri i matchingen.

### F4 — Interne kandidatfelt i offentlig svar (P3, blokker)
`src/index.ts:993-995` legger interne felt på hvert kandidatobjekt, og `:998` sletter bare prisfelt:
```ts
klassifisering: 'CLASS_D_CATALOGUE_CANDIDATE',
matchReason: k.matchReason ?? null,
source: 'GT_AUTO_PRISLISTE',
```
Faktisk svar (målt, ikke teori):
```
kandidatnøkler: attributter, eurokode, klassifisering, matchReason, posisjon, source, varenavn, varenr
```
`frontrute`-grenen er derimot renset korrekt (§2.7). Det er bare CLASS_D-grenen som lekker.

### F5 — `merke`/`modell`/`aar` brukes ikke (P1)
Valideringen krever `regnr || merke || sok`, men bare `regnr` → SVV setter `bil`.
`{"merke":"VW","modell":"TRANSPORTER","aar":2005}` gir `bil: null` og 0 kandidater.
Enten skal parameterne brukes, eller så skal de avvises eksplisitt.

### F6 — pen.dev `fileToken` i public repo (sikkerhet)
Se §2.3. Roter tokenet.

### F7 — Dekningsgap i QA
- Ventilrute har ingen UI-inngang → ikke E2E-testbar i Chrome.
- 7 GT-tester skippes (manglende fixture) → GT-roundtrip ikke målt.

0042–0046 er altså applisert utenfor ledgeren. Bare 0047 mangler reelt.

### Kritisk operasjonell risiko
`0042/0043/0044` bruker **ikke-idempotent** `ALTER TABLE … ADD COLUMN`.
`wrangler d1 migrations apply finnbilglass-db` vil derfor stoppe på 0042 med «duplicate column name»
før den når 0047.
**Kjør aldri `migrations apply` mot prod.** Appliser 0047 alene:
```
npx wrangler d1 execute finnbilglass-db --remote --file=migrations/0047_glass_typekode.sql
```
(0047 er additiv og idempotent: `CREATE TABLE IF NOT EXISTS`, `CREATE INDEX IF NOT EXISTS`,
`CREATE VIEW IF NOT EXISTS`. SHA256 `b6bf1f547a6b15f2876e49ecb26e2b00bf3ec9dbe4d1c5a96bad717ec76125cd`.)

### Rollback
```sql
DROP VIEW IF EXISTS v_glass_med_typekode;
DROP TABLE IF EXISTS glass_typekode;
```
Ingen eksisterende tabell endres av 0047. Data-importen (20 601 typekoder) er et separat steg og kan
kjøres/angres uavhengig.
